# SEMN. SIMBOL. REPREZENTĂRI CULTURALE — GitHub Pages

Static website for the 2026 international conference at Universitatea Petrol-Gaze din Ploiești.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `semn-simbol-2026`).
2. Upload **all three files**: `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the live `github.io` address.

No PHP, WordPress, database, plugin, or build step is required.

## Updating the site

Most conference content is in `index.html`; visual styling is in `style.css`.

The text in the site is based on `Invitație 2026.docx` supplied for this project.
